## 🎯 ROS2 Packages

### cpp_pubsub

**Description**: publish/subscribe of LaserScan messages

**Nodes:**
- `listener` - Subscribes to `/scan` and prints statistics
- `publisher` - Publishes test data

**Topics:**
- `/scan` - LIDAR data (LaserScan)

**Files:**
- `subscriber_member_function.cpp` - Listener code
- `publisher_member_function.cpp` - Publisher code
- `CMakeLists.txt` - CMake configuration

### vehicle_description

**Description**: URDF description of the vehicle for RViz

**Files:**
- `urdf/vehicle.urdf` - Main URDF model

## ⚙️ Installation & Build

### Requirements

```bash
# ROS2 Humble (Ubuntu 22.04)
curl https://repo.ros2.org/ros.key | sudo apt-key add -
sudo apt update
sudo apt install ros-humble-desktop python3-colcon-common-extensions

# Optional dependencies
sudo apt install ros-humble-rviz2
```

### Build

```bash
# Go to the workspace
cd ros2_ece_ws

# Source ROS2
source /opt/ros/humble/setup.bash

# Build every package
colcon build

# Or build a specific package
colcon build --packages-select cpp_pubsub

# Verbose build
colcon build --event-handlers console_direct+

# Source the workspace
source install/setup.bash
```

### Checking the installation

```bash
# List the packages
ros2 pkg list | grep cpp_pubsub

# List the executables
ros2 pkg executables cpp_pubsub
```

## 🚀 Running

### Full start-up (3 terminals)

**Terminal 1: microROS agent**
```bash
docker run -it --rm microros/micro-ros-docker:humble \
  ros2 run micro_ros_agent micro_ros_agent udp4 --port 8888
```

**Terminal 2: ROS2 workspace + listener**
```bash
cd ros2_ece_ws
source install/setup.bash
ros2 run cpp_pubsub listener
```

**Terminal 3: RViz visualisation**
```bash
cd ros2_ece_ws
source install/setup.bash
ros2 launch rviz2 rviz2 -d lidar_config.rviz
```

### Using the scripts

```bash
# Start the listener with statistics
./run_lidar.sh

# Start RViz with the tuned config
./run_rviz.sh

# Full deployment (every service)
./deploy_lidar.sh

# Communication tests
./test_lidar.sh

# Automatic RViz configuration
./setup_rviz_display.sh
```

## 📊 Topics and Messages

### Topic: `/scan`

**Type**: `sensor_msgs/LaserScan`

**Description**: raw LIDAR data (360°)

**Structure**:
```
frame_id: "lidar"
angle_min: 0.0 (radians)
angle_max: 6.28 (2π radians)
angle_increment: 0.0087 (0.5°)
range_min: 0.0 (m)
range_max: 10.0 (m)
ranges: [float32 x 720]  # Distance for each angle
intensities: [float32 x 720]  # Intensity (optional)
```

**Rate**: ~10 Hz

**Reading it**:
```bash
ros2 topic echo /scan
ros2 topic hz /scan
ros2 topic info /scan
```

## 🔧 RViz Configuration

### Pre-configured elements

The `lidar_config.rviz` file includes:

1. **LaserScan Display**
   - Topic: `/scan`
   - Color Transformer: Intensity
   - Min/Max Intensity: 0/255

2. **Global Options**
   - Fixed Frame: `lidar`
   - Background Color: black

3. **Camera**
   - Positioned to view the LIDAR well

### Customising RViz

```bash
# Open RViz and configure it by hand
ros2 launch rviz2 rviz2

# Save the configuration
# Menu: File > Save Config As > lidar_config_custom.rviz
```

For more details, see [RVIZ_CONFIGURATION_GUIDE.md](RVIZ_CONFIGURATION_GUIDE.md).

## 📝 CMakeLists.txt (Standard Structure)

Each package contains a `CMakeLists.txt`:

```cmake
cmake_minimum_required(VERSION 3.8)
project(cpp_pubsub)

find_package(ament_cmake REQUIRED)
find_package(rclcpp REQUIRED)
find_package(sensor_msgs REQUIRED)

add_executable(listener src/subscriber_member_function.cpp)
ament_target_dependencies(listener rclcpp sensor_msgs)

install(TARGETS listener DESTINATION lib/${PROJECT_NAME})

ament_package()
```

## 🚨 Troubleshooting

### "Package not found"
```bash
source install/setup.bash
```

### RViz does not start
```bash
sudo apt install ros-humble-rviz2
```

### No `/scan` messages
1. Check that the microROS agent is running
2. Check that the ESP32 publishes (`ros2 topic echo /scan`)
3. Check the network connection

### CMake build error
```bash
colcon build --event-handlers console_direct+
# Read the full log for the errors
```
