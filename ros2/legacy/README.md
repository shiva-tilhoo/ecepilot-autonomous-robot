# Previous versions

Nodes and scripts replaced along the way, kept to show how the project evolved: extended Kalman filter (`simple_ekf.py`, `kalman_filter_fusion.py`), IMU filtering (`imu_fft_analysis.py`, `imu_fir_filter.py`, `imu_kalman_filter.py`), lifecycle nodes, naive navigation algorithms (`algo_naif*.py`).

These files are in the state they were in at the time and are no longer maintained. The shell scripts locate their files from their own folder; `start_slam_rf2o_only.sh` has a syntax error that was already in the original.

The version to use is at the root of [`ros2/`](..).
